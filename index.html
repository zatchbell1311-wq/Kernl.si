quickstart.py
PYTHON 
from dspm_memory import DSPMMemory
import openai

client = openai.OpenAI(api_key="sk-...")
memory = DSPMMemory(budget=250, llm_client=client)

# Conversation with a revision
memory.add_turn("user",      "Set webhook timeout to 30s.")
memory.add_turn("assistant", "Done.")
memory.add_turn("user",      "Change that to 10s.")
memory.add_turn("assistant", "Updated.")

# Both values survive compression
print(memory.get_context())
# → webhook_timeout: 10 (was 30)

MEMORY DEGRADATION

Context windows eat their own history

Standard memory strategies — rolling truncation, summaries, embeddings — treat every token as equally disposable. A constraint the user stated in turn 2 is gone by turn 30. They don't know it's gone. That's the bug.
