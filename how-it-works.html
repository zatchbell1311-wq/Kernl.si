ARCHITECTURE PIPELINE STAGES T1–T7

7 Deterministic Stages.
One Structural Guarantee.

Each stage has one job. Together they compress conversation memory to any token budget while ensuring every constraint the user stated survives — independent of conversation length.

Pipeline Architecture

GROUP R1
Extract
Stages T1–T2
Deduplication + Slot Fusion. Discovers constraint keys, updates state slots, and resolves revision chains. Fuses overwrites into reversible deltas: "timeout: 10 (was 30)".
GROUP R2
Compress
Stages T3–T5
Delta encoding, causal pruning, and utility scoring. Ranks tokens according to structural relevance and usage frequency. Discards chit-chat and compresses low-value peripheral tokens first.
GROUP R3
Guarantee
Stages T6–T7
Shadow Selection re-injects any displaced critical constraint patch. Adaptive Budgeting strictly enforces the hard token ceiling. The reason 100% CRR is structural rather than heuristic.

Compatibility

Works with every LLM stack

dspm wraps your existing client. No vendor lock-in, no stored API keys, no cloud calls during compression.

OpenAI Groq Together AI Ollama Anthropic (compat.) Any OpenAI-compat. API
Custom Provider Configuration PYTHON 
# Compatible with Ollama, Groq, Together, vLLM, or LocalAI
from dspm_memory import DSPMMemory
import openai

client = openai.OpenAI(
    base_url="http://localhost:11434/v1",  # Local Ollama or custom gateway
    api_key="ollama"
)

memory = DSPMMemory(budget=250, llm_client=client)

Any provider exposing an OpenAI-compatible /chat/completions endpoint works seamlessly with a custom base_url.
