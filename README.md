# Kernl.ai — Dynamic Semantic Patch Memory (DSPM)

The official product and research site for **DSPM** (Dynamic Semantic Patch Memory) — a training-free Python library that compresses LLM conversation memory while structurally guaranteeing 100% Critical Retention Rate (CRR) across any token budget.

Created by **Dhruv Dubey** (Independent AI Researcher).

## Features
- **Editorial Dual-Theme Design**: Warm off-white light mode and deep near-black dark mode with instant system sync and persistence.
- **Animated Glitter Border**: CSS Houdini `@property --border-angle` conic-gradient traveling shimmer tracing the floating hero card.
- **Compresr-Style 40px Line Grid**: Subtle geometric depth with soft ambient radial light leaks.
- **Universal K-Logo Transitions**: Entrance animations and redirect interception ensuring the Kernl.ai signature brand is always displayed before navigating.
- **Verified Benchmarks & Interactive Demos**: Token compression vs LongContext, MemGPT, LangChain.

## Pages
- `index.html` — Homepage with interactive Quickstart, metrics, and recognition.
- `how-it-works.html` — 7 deterministic stages of the DSPM pipeline.
- `benchmark.html` — Retention benchmarks and ablation study.
- `research.html` — Paper details, Zenodo DOI preprint, BibTeX citation modal.
- `about.html` — Dhruv Dubey researcher profile and open-source contributions (Yale, UW, Waterloo).
